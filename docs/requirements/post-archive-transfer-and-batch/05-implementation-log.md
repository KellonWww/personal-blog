## 详细改动记录
### 接口与事务
| 接口 | 说明 |
|---|---|
| POST /api/admin/posts/to-archives | ids 列表，最多 50 篇；返回 created/existing 转档结果 |
| POST /api/admin/posts/batch | ids、action、taxonomyIds；action 为 publish/draft/delete/categories/tags |

- 转档复用现有导入事务，统一生成导入批次和版本审计；集合更新私有分类/标签。
- 写入前在同一事务内校验文章版本；发布再检查档案关联；分类/标签再检查词表有效性。
- 删除同步撤回，避免已发布档案关联稿在删除时触发受保护字段门禁。
- 档案关联包含墓碑，不因软删除或功能关闭而失去普通入口发布保护。
- 普通批量管理探测档案关联表是否存在，兼容尚未执行档案迁移的数据库。
- 数据库原始错误不回显或记录私密正文；超时/结果不明提示刷新核对。
